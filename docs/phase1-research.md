# 阶段一调研简报：惠州校服选购微信小程序

## 结论摘要

- **展示名建议**：惠州校服选购；**仓库**：`school-uniform-wx`
- **MVP 样板**：惠城区 + 惠东县（均不分学段；夏 / 春秋 / 冬）
- **核心链路**：选区县 → 季节套装 / 单品 → 尺码 → 单买或成套 → 下单待支付 → 快递或虚拟自提 → 7 天无理由
- **SKU**：区县 × 季节单品 / 套装 × 尺码；**区际不可混卖**
- **支付**：先可插拔占位；真支付待商户号；小程序支付无独立沙箱
- **不做**：H5 / App、学生身份采集、惠阳学段（二期）、正式提审 / 真收款（未确认前）

---

## 业务硬约束（用户确认）

- 惠州「一区 / 一县一款」共 **7 区**；具体款式清单见业务附件（本简报不展开 SKU 明细表）
- **买方** = 家长；支持**批量**（假设 = 一次下单多件）与**单买 / 成套**；尺码自选
- **自有仓 + 简单库存**；缺货由运营自行补货
- **配送 + 校内自提**；MVP 自提 = 惠城 / 惠东各 1 个**虚拟自提点**
- **7 天无理由**（吊牌在、未穿洗）
- **首期仅小程序**；不采集学生身份；预算 / 上线日 / 商户主体暂未知

## 关键假设 / 开放项 / 风险

### 假设

- **批量** = 家长一次下单多件（非团购 / 班级统购流程）
- **尺码**通用段假设为 **110–180**（待与业务附件核对）
- **虚拟自提**可通过核销码或等价方式验核（具体规则待产品确认）

### 开放项

- 预算、上线时间
- 小程序 **AppId**、微信支付**商户号**及**主体**（公司 / 个体等）

### 风险

- **主体 + 商户号**是上线与真收款的硬闸；占位支付仅适合演示
- **无独立支付沙箱**：沙箱演示 ≠ 真支付链路
- **区县 SKU** 在 MVP 仅两区，全量 7 区未测全，扩区时易漏规则（如区际不可混卖）
- **退换货文案**若与 7 天无理由条件不一致，易在审核或客诉中暴露
