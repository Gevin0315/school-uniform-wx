# MVP 范围：做 / 不做

## 本阶段要做

1. **选区**：惠城、惠东可选；其他区列表灰显「即将开放」
2. **目录与 SKU**：区县级商品（套/单），尺码 110–180，库存展示（可售/缺货）
3. **购物车**：单买、成套、批量加购与数量调整
4. **下单**：生成订单，状态 **待支付**（支付通道占位）
5. **履约选择**：快递地址 **或** 本区虚拟自提点
6. **订单**：列表 + 详情（商品、金额、履约方式、支付/售后状态）
7. **售后**：7 天无理由**申请**（状态机 + 文案），不接自动退款
8. **合规内容**：商品页**退换说明**、**自愿购买声明**
9. **库存后台**：简单加减 SKU 库存（运营向，可云开发控制台或极简管理页）

## 本阶段明确不做

| 类别 | 说明 |
|------|------|
| 多端 | H5、独立 App |
| 代收 | 班级代收、家委统收 |
| 身份 | 学生身份、学籍、班级绑定 |
| 区域扩展 | 惠阳等其他区**正式**开放、学段细分 |
| 上线与支付 | 小程序**正式提审**、**真微信支付**、真实商户进件 |
| 学校对接 | 与真实学校系统/名单/通知对接 |
| 物流 | 真实快递下单、电子面单、轨迹回传 |
| 营销复杂能力 | 优惠券、拼团、分销等（芋道类商城通用模块不在 MVP） |

## 边界说明

- **mock 支付**仅测试环境，且必须标注非真收款
- **虚拟自提点**无扫码核销、无店员端
- 文档与代码以 **Gate 1**（见 `05-acceptance-gate1.md`）为第一阶段交付验收依据
