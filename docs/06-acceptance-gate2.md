# 二闸验收标准（Gate 2）— 占位

> **状态**：待微信支付**商户号**就绪后补充详细用例与勾选清单。本文档仅说明二闸边界，不作为当前开发过线依据。

## 计划覆盖范围（概要）

- **真实微信支付**：下单、支付成功回调、订单状态与对账一致
- **退款**：用户 / 运营触发的退款流程与状态同步
- **订单发货管理**：发货、物流信息、（若适用）批量或后台操作
- **发货 SLA**：例如 **约 48 小时**内发货等业务承诺的验证方式（具体指标待产品与运营确认）

## 依赖

- 商户号、支付密钥与证书（**不得**提交至本仓库）
- 一闸 [05-acceptance-gate1.md](05-acceptance-gate1.md) 已通过或与本闸并行项明确切割
