# 项目简报摘要

## 产品定位

惠州地区校服**自愿选购**微信小程序 MVP，采用「**一区一款**」：每个样板区县展示对应款式目录，其余区县灰显「即将开放」。

## 样板区

| 状态 | 区县 |
|------|------|
| 已开放（MVP） | 惠城区、惠东县 |
| 灰显预告 | 其余区（如惠阳等），不可下单 |

## 买方与选购方式

- **买方**：家长（不采集学生身份信息）
- **选购形态**：单件、成套、批量（一次下单多件）
- **尺码**：通用号型 **110–180**（SKU 维度）

## 履约

- **快递**：填写收货地址，标准快递配送（MVP 不对接真实物流轨迹 API，状态以订单流为准）
- **自提**：每个样板区配置 **1 个虚拟自提点**（名称/地址/说明即可，无线下核销系统）

## 库存

- **自有仓**，不按校实时同步
- 运营通过**简单后台**对 SKU 库存做加减（见架构文档 `adminAdjustStock`）

## 售后

- **7 天无理由**（以签收或约定起算日为准，实现阶段在订单详情固化规则文案）
- 条件：**吊牌在、未穿洗**；申请走状态机 + 固定文案，不接自动退款网关（支付未接前为模拟/占位）

## 合规与表述

- 强调**自愿选购**，禁止强制、指定商家、与入学挂钩等表述
- **不采集**学号、班级、学生证件等身份字段
- 商品页须含：**退换说明** + **自愿购买声明**

## 支付

- **先预留**：微信支付商户号与主体未定时，不接真支付
- **mock 支付**：仅允许在**测试环境**使用，界面与日志须**明确标注「非真收款」**

## 开放假设（待业务确认）

以下信息当前**未知**，文档与排期均带不确定性：

- 项目**预算**与人力
- 目标**上线日**
- **商户主体**（微信支付进件主体）
- 是否与**真实学校/名单**对接（MVP 明确不做）
