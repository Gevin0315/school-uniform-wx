# 惠州校服选购

> 仓库：`school-uniform-wx`  
> 惠州「一区一款」校服自愿选购微信小程序 MVP（惠城 + 惠东）

## 一句话

面向家长的区县隔离校服选购小程序：选区 → 目录 → SKU → 下单；快递或虚拟自提；支付与发货能力预留、可插拔。

## 技术基线

**方案 A**：原生微信小程序 + 微信云开发

- 支付：占位接口，商户号到位后再接；测试环境可用 mock，且须标明非真收款
- 发货管理：预留扩展点，当前不实现真物流对接
- 库存：自有仓，简单后台加减
